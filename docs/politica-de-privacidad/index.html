Política de privacidad

En Medio Pixel valoramos tu privacidad y nos comprometemos a proteger cualquier información que puedas compartir con nosotros.

Aplicaciones y juegos

Salvo que se indique lo contrario en la descripción de la aplicación, nuestras apps y juegos:

  • No recopilan datos personales de los usuarios.
  • No requieren registro, acceso a contactos, ubicación ni información identificable.
  • Pueden utilizar funciones básicas del dispositivo, como vibración o almacenamiento local, exclusivamente para mejorar la experiencia de juego.

Este sitio web

Este sitio web no utiliza cookies ni herramientas de analítica. Está alojado en GitHub Pages, que registra la dirección IP de los visitantes por motivos de seguridad.

Sobre futuras actualizaciones

Si en el futuro alguna aplicación o servicio requiere la recopilación de datos personales, esta política será actualizada con transparencia para informarte de forma clara.
